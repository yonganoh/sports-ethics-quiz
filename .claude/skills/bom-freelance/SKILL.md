# 프리랜서 BOM

외주·프리랜서 프로젝트에 쓰는 **통합 계층형 BOM** 형식이다. 기준 파일은 Drive `00_공통`의 `스킬_참조파일_목록.md`에 적힌 "프리랜서 BOM 기준 파일"이며, 그 안의 `BOM 양식` 시트가 빈 양식이다. 작성 전에 목록 파일을 읽고 기준 파일을 열어 열과 배치가 같은지 확인한다.

## 속성 매핑 (먼저 읽는다)
Drive `00_공통`에서 제목이 `SW_속성_매핑`으로 시작하는 최신 파일을 읽는다. 솔리드웍스 사용자 정의 속성(ARTICLE, DWG No. / SPEC., MATERIAL, FINISH, REMARK, QUANTITY, 단위, MODEL TYPE, MAKER 등)을 이 BOM의 어느 열에 넣는지, 구분을 어떻게 계산하는지 그 문서가 정한다. SW에서 저장한 BOM Excel을 받으면 그 문서대로 열을 맞춘다. 속성이 비어 있으면 지어내지 않고 빈칸으로 두고 목록으로 보고한다. 도면 QUANTITY와 BOM 총 수량이 다르면 알린다.

## 시작 전
1. `00_START`(Drive `00_공통`의 최신 `00_START*`)의 7장 BOM 규칙을 읽는다.
2. 근거 자료(STEP 분석 결과, 설계 계획서, 이전 BOM)를 확인한다. 없으면 부족한 정보 목록을 사용자에게 묻는다.
3. **지시 없이 기존 BOM을 덮어쓰지 않는다.** 새 Rev 파일로 만들고 이전 파일은 `99_이력`에 둔다. 최종 BOM은 사용자가 직접 고친다.

## 파일 구성 (시트 3개)
1. **BOM**: 통합 계층 BOM
2. **구매 발주 목록**: 구매·외주만 구매처별로 모은 목록. 수량·단가·금액은 BOM 시트를 참조 (초록 글씨)
3. **BOM 양식**: 다른 프로젝트용 빈 양식
- 제작품의 개략 비용은 별도 `예상 비용 산출` 시트에서만 계산한다 (재료비 + 가공시간 × 시간단가 + 셋업 ÷ 수량 + 후처리 + 검사·기타).

## BOM 시트 머리말
프로젝트, 문서 번호, 개정(Rev와 기준 STEP 날짜), 작성 / 일자.

## 열
`No | 이미지 | Lv | 품번 | 품명 | 규격·재질 | 개당 수량 | 총 수량 | 단위 | 구분 | 제조사·구매처 | 형번·주문 규격 | 도면 | 단가(원) | 금액(원) | 납기(일) | 구매 주소 | 비고`

## 계층 (Lv)
- 0 = 완제품(최상위 조립), 1 = 큰 묶음(본체부·구동부 등), 2 = 부품 또는 하위 조립, 3 = 하위 조립의 부품
- 행 그룹(토글)을 건다: 왼쪽 위 1/2/3 버튼 (1 = Lv1까지, 2 = Lv2까지, 3 = 전부)
- 개당 수량 = 바로 위 상위 조립 1개에 들어가는 수량. **총 수량 = 개당 × 상위 조립의 총 수량 (수식)**

## 품번 규칙
`AA-xx` 제작 도면 번호 (AA = 프로젝트 약자) / `P-xx` 구매·외주품 / `R-xx` 재사용품 / `F-xx` 체결류 / `C-xx` 소모품.

## 구분
제작 / 구매 / 외주 / 재사용 / 조립(묶음 행, 금액 없음)

## 제조사·구매처 분류
속성 `MODEL TYPE` 값을 그대로 쓴다 (값 목록은 속성 매핑 문서 기준). 구매품은 `READY-MADE · 구매처`로 쓴다.

## 색 규칙
노란 칸 + 파란 글씨 = 사람이 입력(단가·납기) / 검은 글씨 = 고정 값 또는 수식 / 초록 글씨 = 다른 시트 참조.
- 단가와 납기는 **비워 둔다** (견적을 받은 사용자가 입력). 금액, 구분별 합계, 총 합계는 수식으로 자동 계산한다.
- 구분별 합계(제작/구매/외주/재사용 품목 수)와 총 합계(부가세 별도) 행을 맨 아래에 둔다.

## 표기
- 소재: `[재질] [소재 치수] · Anodizing[Clear/10~15μm]` 형식. 공차는 숫자로만, H7 같은 문자 기호는 쓰지 않는다.
- 체결 기본: 소켓볼트 + 평와셔 + 스프링와셔 (카운터보어는 볼트만).
- 값에는 [확정] [가정] [미확인]을 구분해 비고에 적는다. 확인하지 못한 형번은 비워 두고 "확인 필요"라고 쓴다.
- 부품 이미지는 B열에 넣는다. 이미지를 못 만들면 칸을 비우고 말해 준다.
- AI·도구 이름은 쓰지 않는다. 작성자 칸은 사용자 이름만.

## 끝낼 때
1. 수식이 맞는지(총 수량, 합계) 확인하고, 구매 발주 목록이 BOM과 일치하는지 대조한다.
2. 이전 Rev와 달라진 품목을 표로 짧게 보고한다 (품목, 이전, 이번, 이유).
3. 저장 위치는 `06_발표_발주`, 파일 이름은 `#YYYYMMDD_이름 BOM_RevN.xlsx`.
