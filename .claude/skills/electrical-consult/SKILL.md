# 전기 협의표

기구 설계안을 근거로 전기팀과 협의할 항목을 정리한다. 양식은 Drive `00_공통`의 `전기협의표 양식` 최신 Rev(파일 ID는 같은 폴더의 `스킬_참조파일_목록.md`에 있다)이다. 작성 전에 이 파일을 내려받아 시트 구성을 확인하고, **양식 파일 자체는 고치지 않고** 복사해서 쓴다.

## 시작 전
1. `00_START`(Drive `00_공통`의 최신 `00_START*`)를 읽는다.
2. 근거 문서(입력 조건서, 설계 계획서)를 읽는다. 장치 수량 기준(1개 / 좌우 쌍)을 근거에서 확인한다.
3. 정보가 없으면 지어내지 않고 부족한 정보 목록을 사용자에게 묻는다. 에이전트로 실행 중이면 목록을 돌려준다.

## 시트 구성
1. **협의표 요약**: 머리말, 한눈에 보기(3줄), 전기팀에 먼저 물을 것(3개 이내), 안전 우려(1~3개)
2. **전원**: 장치별 전압·전류·전력, 합계 W, 합계 전류, 공급 용량 대비 사용률·여유율 (수식)
3. **커넥터·접지**: 커넥터 종류, 핀 수, **기구 기준 위치**, 방향, 방수 등급, 접지 위치 요구, 기구 쪽 준비(구멍·씰·고정)
4. **케이블 경로**: 구간, 외경, 길이, 최소 굽힘 반경, 슬랙, 고정 방법, 진동·이동 구간
5. **개폐기·보호**: 정격, **DC 사용 가능 여부**, 설치 위치
6. **협의 이력**: 질문, 대상, 상태(협의 전 / 협의 중 / 합의), 결정 내용, 반영 위치(도면·품번), 반영 여부

## 규칙
- 노란 칸 + 파란 글씨 = 입력, 검은 글씨 = 수식. 수식은 지우지 않는다.
- 모든 값에 [확정] [가정] [미확인]을 붙인다. 근거 없는 값은 [가정]으로 표시하고 비워 두는 편이 낫다.
- 전원 합계 뒤에 **쉬운 말 한 줄**을 붙인다 (예: 켜진 장치가 쓰는 전력이 전원 용량의 몇 %인지).
- 여유율 기준은 전기팀과 협의해서 정한다. 임의 기준을 확정처럼 쓰지 않는다.
- 합의된 항목은 반영 위치(도면·품번)까지 적어야 닫는다. 반영되지 않은 합의는 "미반영"으로 남긴다.
- 지시 없이 도면·BOM·모델·Drive 파일을 고치지 않는다. 협의 결과로 바뀌는 기구 쪽 변경은 목록으로 따로 정리해 보고한다.
- AI·도구 이름을 쓰지 않는다. 작성자 칸은 사용자 이름만.

## 끝낼 때
1. 수식 오류(#값, #참조)가 없는지 확인하고, 시트를 PNG로 뽑아 글자가 잘리지 않았는지 눈으로 본다.
2. 저장 위치는 `03_전기협의표`, 파일 이름은 `#YYYYMMDD_이름 전기협의표_RevN.xlsx`.
3. 전기팀에 먼저 물을 것과 안전 우려를 채팅에 3줄로 요약해 보고한다.
